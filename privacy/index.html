Политика конфиденциальности

Как работают данные в этом превью.

Форма записи

Имя, телефон, выбранное направление и удобное время используются только в вашем браузере для подготовки текста сообщения. Этот сайт не отправляет форму в клинику и не сохраняет имя или телефон в своём хранилище. При закрытии окна записи поля очищаются.

Хранение выбранного направления

В sessionStorage сохраняется только выбранное направление помощи. Оно нужно, чтобы выбор оставался при переходах между страницами в текущей вкладке. После завершения сессии вкладки эти данные удаляются браузером.

Копирование сообщения

Сообщение попадает в буфер обмена только после нажатия «Скопировать сообщение». Дальнейшая отправка выполняется вами самостоятельно. При закрытии окна записи уже скопированный текст остаётся в системном буфере обмена.

Загрузка сайта

При открытии страницы браузер запрашивает файлы сайта у сервера. Сервер может получать технические сведения о запросах. В локальном превью сервер ведёт стандартный журнал обращений. На страницах не подключены внешняя аналитика, рекламные трекеры и внешние шрифты.

Статус документа

Этот документ описывает текущий дизайн-превью. Оператор клиники, контакты для обращений и условия обработки данных при реальной записи пока не предоставлены. До запуска действующего сайта клиника должна подтвердить эти сведения и опубликовать соответствующую политику.
