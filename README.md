# Neurolab Plus

Локальный дизайн-превью. Главная, каталог услуг, неврология, политика конфиденциальности и условия использования.

## Запуск

Из этой папки:

```sh
python3 -m http.server 4173 --bind 127.0.0.1
```

Открыть http://127.0.0.1:4173/. Ссылки на ресурсы начинаются от корня сайта, поэтому нужен HTTP-сервер, а не двойной клик по HTML.

## Видео в hero

Поместить готовое видео в `assets/` и указать путь в `site-config.js`:

```js
heroVideo: '/assets/clinic-hero.mp4',
heroVideoMobile: '/assets/clinic-hero-mobile.mp4'
```

Без видео показывается текущая иллюстрация. Есть управление воспроизведением, пауза вне экрана/скрытой вкладки и учёт reduced motion и экономии трафика. Работа с реальным видео на iPhone требует проверки после получения файла.

## Дизайн

Основные стили: `styles.css`. Композиция главной: `art-direction.css`.
Поведение формы, документов, профилей, поиска и skeleton-состояний: `app.js`.

Документы представлены реестром с отдельной панелью, врачи представлены разворотом с переключением профиля. Фиолетовый сохранён в hero, портрете, переключателях и документах. Углы прямые, без hover-анимаций, стекла, теней, градиентов и библиотеки иконок.

Исходные `scrollcraft.css` и `scrollcraft.js` сохранены, но больше не подключаются: текущая версия не использует их декоративные эффекты.

## Контент перед публикацией

Форма только подготавливает сообщение, не отправляет данные и не создаёт запись. Закрытие окна очищает форму. В sessionStorage остаётся лишь выбранное направление.

Нужны реальные фото и данные врачей, видео, оригиналы документов, контакты, юридические реквизиты и подтверждение условий/цен. Политика и условия описывают только этот режим превью. Утверждённые документы действующего сайта должна предоставить клиника. Изображения остаются явно обозначенными иллюстрациями.
