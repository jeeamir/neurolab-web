# Neurolab Plus

Сайт клиники: главная, услуги, неврология, политика конфиденциальности и условия использования.

## Запуск локально

```sh
python3 -m http.server 4173
```

Открыть http://127.0.0.1:4173/

## GitHub Pages

Все пути к стилям, скриптам и картинкам относительные (`styles.css`, `../styles.css`, `assets/...`).
Поэтому сайт работает и по адресу `https://<user>.github.io/neurolab-web/`.
**Не пишите пути со слэшем в начале** (`/styles.css`, `/assets/...`): на GitHub Pages они ведут в корень домена, и стили пропадают.
Файл `.nojekyll` отключает обработку Jekyll.

## Видео на первом экране

Сейчас стоит заглушка `assets/hero-placeholder.mp4` (медленный наезд камеры на постер).
Чтобы поставить видео клиники, положите файл в `assets/` и поменяйте путь в `site-config.js`:

```js
heroVideo: 'assets/clinic-hero.mp4',
heroVideoMobile: 'assets/clinic-hero-mobile.mp4' // необязательно, вертикальная версия
```

Рекомендации к видео: 10–20 секунд, без звука, 1920×1080, H.264, до 5–6 МБ. Пока видео грузится, виден постер `assets/hero-film-poster.webp`, его тоже стоит заменить кадром из видео.

## Файлы

- `styles.css` — общие стили, шапка, подвал, страницы услуг, неврологии, документов, окна записи.
- `art-direction.css` — стили только главной.
- `app.js` — запись, фильтры услуг, вкладки, окна.
- `hero-media.js` — видео на главной.
- `scrollcraft.css`, `scrollcraft.js` — старые файлы, не подключены, можно удалить.

## Перед запуском

Форма пока только готовит текст сообщения и ничего не отправляет. Нужны реальные фото и данные врачей, видео, документы, адрес, телефон, график и юридические реквизиты: места для них помечены `[НУЖНО: ...]`.
