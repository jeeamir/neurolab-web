Нужно ли заранее проходить МРТ? +

Для записи на первую консультацию готовое исследование не требуется. Возьмите результаты, которые уже есть. Необходимость новых обследований обсуждается с врачом.

Какие две процедуры входят бесплатно? +

По брифу клиники, после консультации предусмотрены две процедуры, которые подбираются индивидуально по показаниям. [НУЖНО: перечень процедур, ограничения и условия предложения].
